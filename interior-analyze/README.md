# 室內空間分析｜撞色曲線客廳 / Interior Analysis — Colour-Block Curve Living Room

單一檔案的互動 3D 簡報（`index.html`）：從**一張室內照片**推測照片外看不到的牆面與房間，重建成可以環視的 3D 空間，再逐章分析尺度、動線、光、風、熱、聲音與風格，最後提出設計策略。

- 18 章：封面、原圖與推測、空間總覽（3.5D 軸測，含天花仰視）、平面／天花與剖面、爆炸圖、機能分區、動線、視域、空間序列、收納量、日照、自然通風、冷氣與溫度、聲環境、色彩計畫、材質與風格、軟裝配置、總結。
- 拍攝相機以畫框、拱門、矮櫃、拱窗 11 個特徵點擬合（站姿約 160 cm、超廣角），照片看不到的部分以**藍色斜線**標示，任何角度都正確。
- 圖面（第 03 章）：平面、天花平面圖（各區天花高、造型天花、木格柵、嵌燈、間接光、冷氣出風口）、縱剖 S1／S2 與橫剖 S3／S4、剖立面 A～D。剖到的牆與樓板塗黑、看到的牆面與家具由遠到近遮擋，尺寸與名稱都放在圖外；圖面可縮放、平移。
- 天花：第 02 章「天花仰視」把相機轉到地板下方往上看（往上拖過地平線也會切換），第 04 章爆炸圖點天花層會由下往上看；人眼視角往上拖就是抬頭。
- 平面與剖面、分區泡泡圖、動線（A*）、視域（Isovist）、日照（NOAA）、通風（D2Q9 格子波茲曼法）、溫度、噪音都由同一份案例資料在瀏覽器中即時計算。
- 四種風格一鍵換裝（撞色曲線、侘寂、北歐、工業風），八個材質槽可逐項調整，主要家具可點選替換。
- 中英文切換；桌機左右分欄，手機直式為上方章節列＋底部抽屜面板。

## 開啟

用瀏覽器直接開啟 `index.html`（需要連網載入 three.js 0.149 與字型）。網址加 `#sun`、`#wind` 等可直接開某一章，加 `?lang=en` 開英文版。

## 說明與限制

- **原圖未公開**：原始照片作者不明，此公開版不含原圖；封面與第 01 章改用「原圖視角」的 3D 重建畫面。色票為由原圖萃取的顏色數值。
- **推測**：右牆主入口與玄關、影音牆、第二扇與對稱拱窗、廚房、餐廳與廚房的窗，都是依建築邏輯推測，非實際空間。照片中餐廳的透視與客廳不一致（疑為 AI 生成圖），3D 依建築邏輯擺正。
- **示意級分析**：日照、通風、溫度、聲環境用於溝通設計概念，不是工程模擬或認證。通風為 2D 平面流場，風速比適合比較不同開窗方案，不適合看絕對值。
- 太陽位置：NOAA Solar Calculator 公式，地點台中（24.15°N、120.67°E）。季節風向沿用臺中國家歌劇院基地分析（Weather Spark／中央氣象署臺中站）。
- 收納率參考值（樓地板 10–15%）為示意。
