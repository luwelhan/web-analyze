# 臺中國家歌劇院基地環境分析 / National Taichung Theater — Site Analysis

單一檔案的互動 3D 簡報（`index.html`），逐章閱讀臺中國家歌劇院（伊東豊雄設計，2016 年開幕）與七期重劃區之間的關係。

- 1920×1080 簡報版面，可自動播放、拖曳旋轉、滾輪縮放；中英文切換、明暗主題（預設淺色白模型）。
- 19 章：封面、時程、區位、量體、立面、曲牆、機能、綠化、日照、反光、遮蔭、風場、能源、視野、天際線、動線、剖面、公益、回應。
- 歌劇院模型在瀏覽器中即時生成：立面開口依照片量測／推估，內部「美聲涵洞」曲面以曲面場生成，可剖切檢視。
- 周邊建物、道路、公園、捷運與公車站取自 OpenStreetMap；步行與開車路線以 OSM 路網計算最短路徑。

## 開啟

用瀏覽器直接開啟 `index.html`（需要連網載入 three.js 0.149 與字型）。
