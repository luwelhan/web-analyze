# Web Analyze

網頁形式的建築、基地與室內分析作品集。每個子資料夾是一個獨立、可直接開啟的分析網站。

| 資料夾 | 內容 |
| --- | --- |
| [`ntt-site-analyze/`](ntt-site-analyze/) | 臺中國家歌劇院基地環境分析：互動 3D 簡報，19 章（日照、反光、遮蔭、風、能源、視野、動線、立面、曲牆、剖面等） |
| [`interior-analyze/`](interior-analyze/) | 室內空間分析（撞色曲線客廳）：從一張室內照片推測完整空間的互動 3D 簡報，18 章（原圖與推測、總覽與天花仰視、平面／天花平面／縱橫剖面、爆炸圖、分區、動線、視域、序列、收納、日照、通風、冷氣溫度、聲環境、色彩、風格、軟裝、總結） |

## 開啟方式

下載或 clone 後，直接用瀏覽器開啟各子資料夾裡的 `index.html`。頁面會從網路載入 three.js 與 Google Fonts，所以開啟時需要連網。
